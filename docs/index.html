How to Install, Play & Master Every Shortcut

Everything you need to run Dih Client cleanly from first boot to ranked play — default keybinds, Minimal vs Complete HUD modes, GLSL shader skin baking, Corsair RGB sync, and layout customization.

STEP 01 • INSTALL & LAUNCH

Platform Setup

  • Windows (779.5 KB Native): Extract Dih-Client-v0.4.1-win-x64.zip keeping Dih.exe and WebView2Loader.dll in the same folder, then run Dih.exe (uses built-in Windows 10/11 Edge WebView2).
  • macOS (ARM64 / x64): Unzip into Applications. If macOS Gatekeeper warns on unsigned bundles, run xattr -cr /Applications/Dih.app once in Terminal.
  • Linux (x64): Extract tar -xzf Dih-Client-0.4.1-linux-x64.tar.gz and launch ./dih-client cleanly with executable bits intact.
STEP 02 • AUTO-TUNE & LOBBY

First Boot & Menu Access

  • Boot Hardware Analyzer: Scores your CPU, GPU, and monitor refresh rate (PowerScore) to auto-configure render scale, graphics backend (D3D11/Metal/Vulkan), and frame pacing.
  • Open Bento Panel: Press RightShift or O at any time to open the Titanium Glass Command Center (Esc closes it).
  • Drag & Customize HUD: While Command Center is open, drag the Telemetry, Keystrokes, Watermark, K/D Card, or Stopwatch widgets anywhere on screen.
STEP 03 • MATCH PLAY & PRIVACY

In-Match Tips & Rebinding

  • Zero-Leak Adblocker: Blocks Venatus, Atmtd, and ad trackers at the network layer automatically with zero setup.
  • Auto-Join Match Chat: Broadcasts your configured greeting (default "Dih User Joined") automatically on lobby-to-match transitions (toggle or customize in Command Center).
  • Rebind Any Shortcut: Open RightShift → search "hotkey" to rebind any key below; press F9 anytime for instant clip/stream Clean Mode.
